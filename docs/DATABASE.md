# Database reference

PostgreSQL 16. Generated by `tools/gen-db-doc.py` from the live schema after migrations `001_init.sql`, `002_ai_provider.sql`, `003_data_version.sql`. Internal IDs are immutable; business IDs (employee no., fleet no.) are separate and unique (§13.1).

| Table | Purpose |
|---|---|
| `action_events` | Status history of each renewal action. |
| `ai_interactions` | Log of AI questions, the path that answered and the record references returned (§12). |
| `asset_categories` | Vehicle / machine categories; new ones need no code change (§2.2). |
| `assets` | Vehicle / machine master (§8.1). |
| `audit_events` | Append-only audit trail; a trigger refuses UPDATE and DELETE (§4.1). |
| `companies` | Group companies: operating, registered and visa-sponsoring (§5). |
