## 1. Executive Summary

*Apply the same successful concept proposed for employees: ONE ASSET → ONE PROFILE → ALL INFORMATION & DOCUMENTS.*

### Current Challenge
- More than 100 heavy vehicles, light vehicles and machines to control
- Registration, insurance, safety certificates and other documents maintained in separate files / records
- Expiry dates require manual checking and follow-up
- Finding the latest document copy can take time
- Management has limited consolidated visibility of asset-document status

### Proposed Solution
- Create one permanent digital profile for every vehicle or machine
- Store key particulars and scanned documents together
- Automatically highlight approaching expiries
- Route alerts to the responsible officer
- Provide dashboard visibility across the complete fleet
- Use AI assistance to find records and summarize matters requiring attention

> The Vehicle Management module is proposed as a companion to the Employee Management module and can later operate inside one integrated Adroit management platform.

## 7. Vehicle Document Control Process

*A simple repeatable process for every registration, insurance, safety certificate or permit.*

| Step | Stage | Description |
|---|---|---|
| 1 | **Record** | Create / update document record |
| 2 | **Upload** | Attach scanned digital copy |
| 3 | **Monitor** | System watches expiry date |
| 4 | **Alert** | Responsible officer is notified |
| 5 | **Renew** | Renewal action is completed |
| 6 | **Update** | New document replaces current record; history retained |

> **Result:** current document + expiry status + renewal history remain attached to the same vehicle throughout its lifecycle.

## 10. Recommended Implementation & Approval

*Develop the Vehicle module in parallel design standards so it can later merge naturally with Employee Management.*

Confirm Fleet Requirements → Design Vehicle Profile → Build Prototype → User Review → Management Review → Controlled Rollout

### Recommended Approach
- Use the same visual standards as the HR system
- Assign a unique fleet / asset number to each vehicle or machine
- Clean and verify existing vehicle records before migration
- Upload current documents first; historical records can follow
- Introduce expiry alerts only after responsible officers are confirmed
- Roll out to a controlled user group before full implementation
